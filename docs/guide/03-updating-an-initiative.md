# Updating an initiative

You can update **an initiative you own**; the Dean and the dashboard admin can
update any initiative.

## How to update

1. Open the initiative — from the Initiatives list, or from your name on the
   People page.
2. Choose **Update**.
3. Set the **status** and the **percent complete**, and add a short **note** if it
   helps the reader.
4. Save.

Each update is a new diary entry. The initiative keeps its whole history; the
card shows the latest entry, and nothing is overwritten.

## What not to do

- **Do not** type an owner's name as free text. Ownership is a link to a real
  person; an admin sets it.
- **Do not** treat the percent as a precise measurement. It is the owner's
  estimate, entered in whole numbers.

## Who may do what

| Action | Who |
|---|---|
| Read every page | anyone signed in |
| Update an initiative | the owner, the Dean, or the dashboard admin |
| Edit tags, links, or retire | the dashboard admin |
| Create an initiative | the dashboard admin |

If a button you expect is missing, it is because your account does not hold the
role — the server refuses the action too, it is not only hidden.
